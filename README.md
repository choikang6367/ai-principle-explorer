# AI 원리 탐험

초등학교 6학년 학생이 생성형 AI의 기본 사용법부터 직접 질문하고, AI가 글을 만들고 이미지를 읽고 그림을 만들어 가는 과정을 한 장면씩 체험하는 인터랙티브 웹사이트입니다. 시작 화면에서 대화, 이미지 인식, 이미지 생성 세 탐험 중 하나를 고를 수 있습니다.

## 체험하기

[AI 원리 탐험 바로가기](https://choikang6367.github.io/ai-principle-explorer/)

## 무엇을 배우나요?

AI를 검은 상자처럼 외우기보다, 질문 하나를 따라가며 다음 흐름을 직접 살펴봅니다.

1. 질문을 입력하면 답변이 출력되는 생성형 AI의 기본 사용법 살펴보기
2. 완성된 질문 중 하나를 골라 AI에게 직접 물어보기
3. AI가 질문을 받기 전에 예시를 보며 배우는 과정 살펴보기
4. 질문을 작은 말 조각으로 나누기
5. 앞에서 어떤 말을 참고할지 고르고, 고른 단서로 다시 계산하기
6. 다음에 올 수 있는 말을 후보로 비교하기
7. 답변을 한 조각씩 붙이며 반복해서 생성하기
8. 답변이 질문에 맞는지, 안전한지, 근거가 필요한지 확인하기
9. 내가 고른 방향과 AI가 고른 방향을 나란히 비교하고 답변 완성하기

Transformer 설명은 어려운 계산 이름 대신 레고 블록, 숫자 이름표, 손전등, 미래 가리개, 여러 탐정 같은 비유로 여섯 단계에 걸쳐 안내합니다.

이미지 인식 원리 체험에서는 공개 라이선스 사진 10장 중 하나를 고르고, 사람이 사진을 보는 장면부터 픽셀의 RGB 숫자, 작은 특징, 후보별 가능성, 사람과 AI의 예상 비교까지 5단계로 따라갑니다.

이미지 생성 원리 체험에서는 주인공·행동·장소·스타일·분위기 단서를 골라 프롬프트를 만들고, 의미 단서와 숫자 지도를 거쳐 무작위 노이즈가 여러 단계로 정리되는 흐름을 살펴봅니다. 잠재 공간과 디코더의 비유, 한 단서만 바꾼 전후 비교, 결과 검사 체크리스트까지 이어지며 글 생성 체험과는 별도로 진행 상황을 저장합니다.

## 주요 기능

- 동물·사람·일상·과학·학교 5개 주제
- 총 150개 질문과 지식형·상상형·선택·의견형 질문 유형
- 글자 사이를 직접 눌러 문장을 나누어 보는 활동
- 앞의 말에서 어떤 단서를 참고할지 고르는 활동
- 다음 말 후보와 가능성을 비교하는 활동
- 내가 나눈 토큰과 고른 단서를 다음 계산에 반영하는 활동
- 답변을 한 조각씩 이어 붙이는 반복 생성 과정
- 답변을 공유하기 전 안전성·질문 적합성·근거를 확인하는 과정
- 새로고침 후 진행 상황을 이어 보는 로컬 저장
- 키보드 조작과 모바일 화면 지원
- 질문 입력·답변 출력 채팅 예시와 직접 질문하기 화면
- Transformer의 여섯 단계를 따라가는 쉬운 설명과 계산 예시
- 이미지 인식의 5단계 흐름: 사진 선택 → 픽셀·RGB 숫자 → 특징 → 가능성 → 결과 비교
- 공개 라이선스 사진 10장과 사진별 픽셀 위치·색상·특징 위치를 연결한 선택형 이미지 인식 활동
- 이미지 생성의 10단계 흐름: 프롬프트 → 의미 단서 → 숫자 지도 → 노이즈 → 정리 → 잠재 공간 → 비교 → 검사
- 주인공·행동·장소·스타일·분위기를 조합하는 선택형 이미지 프롬프트
- 단계별 로컬 SVG 7장과 결정적인 교육용 구성 그림을 이용한 노이즈 정리 시각화
- 장소·스타일·분위기 중 한 단서를 바꾸는 전후 비교와 사람이 직접 확인하는 6개 체크리스트

## 교육용 모형 안내

이 프로젝트는 실제 생성형 AI API를 호출하지 않습니다. 화면에 나오는 답변 후보, 확률, 토큰화 결과, Transformer 숫자와 반복 생성은 원리를 쉽게 보여 주기 위해 만든 교육용 모형입니다.

- 실제 GPT의 가중치나 내부 생각을 재현하지 않습니다.
- 학습 화면은 많은 예시를 보고 숫자를 조절하는 원리를 설명하며, 브라우저에서 실제 대규모 학습을 실행하지 않습니다.
- 반복 생성 화면도 고른 교육용 답변 재료를 한 조각씩 보여 주는 모형이며, 실제 모델의 전체 어휘를 사용하지 않습니다.
- 화면의 숫자는 실제 AI의 중요도나 정답 확률이 아닙니다.
- 안전성·근거 확인은 꼭 필요한 점검 항목을 연습하는 장치이며, 실제 사실 검증이나 안전 보증을 대신하지 않습니다.
- 토큰화 결과는 모델·언어·어휘에 따라 달라질 수 있습니다.
- 사실형 질문의 답은 별도의 믿을 만한 자료로 다시 확인해야 합니다.
- 이미지 인식 화면의 픽셀 위치·RGB 값·특징 영역·가능성은 사진을 읽는 원리를 설명하기 위한 교육용 예시이며, 실제 모델의 내부 상태나 정답 확률이 아닙니다.
- 이미지 생성 화면의 숫자 지도와 단계별 그림은 실제 모델의 잠재 표현, attention map, 내부 생각을 보여 주지 않는 교육용 비유입니다. 확산 기반 모델의 일반적인 흐름을 단순화했으며 모델마다 구조와 생성 방식이 다를 수 있습니다.
- 이미지 결과는 사실의 증거, 개인정보 보호, 편견 없는 표현, 저작권을 보장하지 않습니다. 손·글자·개수·겹침을 확인하고 다른 사람의 얼굴이나 개인정보를 허락 없이 넣지 않도록 안내합니다.

이미지 인식 체험의 사진 출처와 라이선스는 [이미지 출처 및 라이선스](public/images/image-experiences/SOURCES.md)에서 확인할 수 있습니다. 이미지 생성 체험의 그림 자료는 `public/images/image-generation/`에 포함된 자체 제작 로컬 SVG입니다. 외부 이미지 생성 API나 외부 이미지 요청은 사용하지 않습니다.

## 로컬에서 실행하기

Node.js 22 이상이 필요합니다.

```bash
npm ci
npm run dev
```

실행 후 터미널에 표시된 로컬 주소를 브라우저에서 열면 됩니다.

## 검증과 빌드

```bash
npm test
npm run build
```

`npm test`는 안전성, Transformer 계산, 질문 데이터, 이미지 인식·생성 데이터, 진행 상황 저장을 검사합니다. `npm run build`는 TypeScript 검사와 배포용 번들 생성을 수행합니다.

## 배포

`main` 브랜치에 변경사항을 올리면 [GitHub Actions 배포 워크플로](.github/workflows/deploy.yml)가 자동으로 검증하고 GitHub Pages에 배포합니다.
